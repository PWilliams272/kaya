Every color/radius/shadow/spacing value above is a CSS custom property, not a hardcoded value — see the token block at the top of this file's <style> for the complete list. Pills (route-type chips, badges) stay fully rounded (999px) by design; the sharp-corner rule applies to containers/cards/inputs, not tags. Tabs are underline-style, not filled buttons.
