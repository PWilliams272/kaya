Diagnostics

Reported honestly, per parameter block — some of this model mixes well and some does not, and the difference matters for which numbers on this page can be trusted.

The sampler hits maximum tree depth on essentially every iteration (1,023 leapfrog steps per draw). The cause is structural rather than fixable by reparameterisation: 59% of climbers appear at only one gym, so for those climbers the personal ability offset, the observation noise, and the gap all compete to explain a single residual. Four separate reparameterisations were tried; none moved it.

Reproducibility. Model in src/kaya/grading_model_v2.py. Network selected as the largest set of gyms connected by ≥50 shared climbers — connectivity is what makes gym corrections identifiable at all. Body measurements outside 4′0″–7′0″ and |ape| > 12in are treated as missing, not believed.
