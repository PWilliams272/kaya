Where every number on this page comes from

Nothing here is hand-typed into the markup. Each section reads a precomputed JSON payload, and each payload is written by one script in this repo. If a number on this page looks wrong, the script named beside it is the thing to re-run — and if a script is re-run, the page changes with it, which is the point.

Payload Written by Feeds
v2_results.json scripts/build_v2_results.py height-form comparison, posterior summaries, sampling statistics
v2_posterior.json scripts/build_v2_posteriors.py posterior distributions, trace plots, corner plots, sampler diagnostics
v2_vs_null.json scripts/build_v2_vs_null.py scores against a fixed no-height reference, with per-row error bars
v2_reliability.json scripts/build_v2_reliability.py refit-to-refit noise floor, per-subset scores, unreliable-row counts
v2_arm_params.json scripts/build_v2_arm_params.py original vs. offsets-integrated-out parameter comparison
v2_time.json scripts/build_v2_time.py climber advancement rate, date/correction confound
v2_kfold.json scripts/build_v2_kfold.py grouped k-fold held-out scores (pending the fold refits)
v2_samplers.json scripts/compare_samplers.py cross-sampler agreement, shared parameters only
v2_emcee.json scripts/build_v2_emcee.py the emcee run in full — chains, posteriors, autocorrelation, walker health, and the 29 gym corrections as both samplers see them
runs/results/sigma_gym_check.json scripts/check_sigma_gym.py the three eliminated explanations for the \(\sigma_{\text{gym}}\) disagreement; folded into v2_emcee.json

The fits themselves come from scripts/run_fit.py and scripts/run_batch.py, which write traces and a per-run results JSON under runs/. Both fit inputs — runs/networks.json (the gym-network definitions) and runs/base_bouldering.pkl (the send snapshot) — are documented in DATA_STORAGE_NOTES.md.
