A Bayesian Grading Model for Climbing Ability

Climbing grades are subjective — the same boulder problem might be called V5 at one gym and V6 at another. This project builds a hierarchical Bayesian model that separates a climber's underlying ability from gym-specific grading style, using nothing but the grades climbers already log in the Kaya app. It's an active investigation, not a finished paper — several sections below end with an open question rather than an answer, on purpose.
